
# 06. V0.2 RAG 知识库问答 + Codex 上下文增强

## 1. V0.2 目标

V0.1 的 `aimem ask` 可以先用关键词搜索。  
V0.2 要升级为真正的个人 RAG。

目标：

```text
右侧 AI 可以问全库
CLI ask 可以基于全库回答
aimem context 可以生成更准确的 Codex 上下文
回答必须带来源
```

## 3. RAG 流程

```text
用户问题
  ↓
生成 query embedding
  ↓
向量检索 topK
  ↓
全文检索 topK
  ↓
混合排序
  ↓
构造上下文
  ↓
调用 LLM
  ↓
返回答案 + 来源
```

## 4. 数据表新增

```sql
CREATE TABLE chunks (
  id TEXT PRIMARY KEY,
  note_id TEXT NOT NULL,
  content TEXT NOT NULL,
  chunk_index INTEGER NOT NULL,
  hash TEXT,
  vector_id TEXT,
  token_count INTEGER,
  created_at TEXT NOT NULL
);

CREATE TABLE embedding_jobs (
  id TEXT PRIMARY KEY,
  chunk_id TEXT NOT NULL,
  status TEXT NOT NULL,
  error TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

---

## 5. chunk 规则

```text
优先按 Markdown 标题切分
每个 chunk 300~800 中文字
代码块尽量保持完整
保留标题路径
保留 note_id、project、tags、type
```

chunk 示例：

```json
{
  "noteId": "note_01",
  "title": "登录失败排查流程",
  "headingPath": ["原因分析", "Cookie 问题"],
  "content": "...",
  "project": "my-app",
  "tags": ["auth", "bugfix"]
}
```

## 6. Codex context 格式

`aimem context` 生成的内容要专门适配 Codex。

```md
# AI Memory Context for Codex

## Current Task
用户当前问题：登录失败 cookie token

## Relevant Past Knowledge

### 1. 登录失败排查流程
- 类型：Bug 修复
- 项目：my-app
- 标签：#auth #cookie
- 相关度：0.91

关键内容：
...

### 2. OAuth 回调失败问题
...

## Suggested Debug Checklist
1. 检查 cookie 是否写入成功
2. 检查 SameSite / Secure / Domain
3. 检查 token 过期时间
4. 检查后端 401 返回
5. 检查前端路由守卫

## Instruction for Codex
请基于以上历史经验排查当前项目。优先验证历史上出现过的问题，但不要盲目套用。
```
