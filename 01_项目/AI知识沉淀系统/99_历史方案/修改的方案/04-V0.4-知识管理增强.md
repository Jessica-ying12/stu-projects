# V0.4 - 知识管理增强

## 目标

完善知识库的管理、编辑、导出能力。

---

## 需求拆分

### 需求 0.4.1：Markdown 笔记编辑器

**描述：** 用户可以编辑 AI 生成的笔记，添加自己的理解

**验收标准：**
- 所见即所得的 Markdown 编辑体验
- 支持实时预览
- 支持常用 Markdown 语法（标题、列表、代码块、表格、链接）
- 自动保存（防丢失）
- 编辑历史可撤销

**具体步骤：**
1. 选择编辑器库（推荐 `@milkdown/core` 或 `@bytemd/react`）
2. 创建 `src/components/MarkdownEditor.tsx`
3. 配置编辑器插件（代码高亮、表格、快捷键）
4. 实现自动保存（debounce 1s 后保存）
5. 实现编辑/预览模式切换
6. 连接数据库更新接口

**额外依赖：**
```bash
pnpm add @milkdown/core @milkdown/preset-commonmark @milkdown/theme-nord @milkdown/plugin-history
# 或者更轻量的方案：
pnpm add @bytemd/react bytemd @bytemd/plugin-highlight @bytemd/plugin-gfm
```

### 需求 0.4.2：自定义分类管理

**描述：** 用户可以创建、编辑、删除自定义分类

**验收标准：**
- 查看所有分类（树形结构）
- 创建新分类（支持子分类）
- 重命名分类
- 删除分类（需确认，内容移到"未分类"）
- 拖拽调整分类顺序
- 合并分类

**具体步骤：**
1. 创建 `src/pages/CategoryManagePage.tsx`
2. 创建 `src/components/CategoryTree.tsx` - 树形分类组件
3. 创建 `src/components/CategoryForm.tsx` - 分类创建/编辑表单
4. 实现拖拽排序（`@dnd-kit/core`）
5. 实现分类 CRUD 的 IPC 接口
6. 在侧边栏展示分类树，点击筛选

**新增数据库表：**
```sql
CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  parent_id TEXT,
  sort_order INTEGER DEFAULT 0,
  icon TEXT,
  created_at TEXT NOT NULL,
  FOREIGN KEY (parent_id) REFERENCES categories(id)
);
```

### 需求 0.4.4：笔记状态流转

**描述：** 笔记有明确的生命周期状态

**验收标准：**
- 状态：待整理 → 已整理 → 已确认 → 已归档
- AI 生成的笔记初始为"待整理"
- 用户审阅后可标记为"已确认"
- 不需要的可归档
- 可按状态筛选笔记
- 批量操作（批量确认/归档）

**状态说明：**
| 状态 | 含义 |
|------|------|
| pending | AI 刚生成，待用户审阅 |
| draft | 用户编辑中 |
| confirmed | 用户确认，正式知识 |
| archived | 已归档，不常用但保留 |

**具体步骤：**
1. 创建 `src/components/NoteStatusBadge.tsx` - 状态标识
2. 创建 `src/components/StatusFilter.tsx` - 状态筛选
3. 实现状态流转逻辑
4. 在笔记列表添加状态筛选
5. 实现批量操作（多选 + 批量更新状态）
6. 添加"待整理"数量提示（侧边栏 badge）

### 需求 0.4.5：知识去重提示

**描述：** 导入新对话时，检测是否与已有知识重复

**验收标准：**
- 新对话导入时检查相似度
- 相似度 > 70% 时提示用户
- 提示内容包含已有笔记的链接
- 用户可选择：合并 / 独立保存 / 忽略
- 不阻塞导入流程（异步提示）

**具体步骤：**
1. 创建 `electron/services/processor/deduplicator.ts`
2. 实现基于关键词的简单相似度计算（TF-IDF 或 Jaccard）
3. 在导入流程中添加去重检查
4. 创建 `src/components/DuplicateAlert.tsx` - 重复提示组件
5. 实现合并笔记逻辑
6. 后续版本可升级为向量相似度
