# 08. V3.0 团队、社区、商业化与超级管理员后台

## 1. 版本目标

V3.0 是商业化版本。

核心方向：

```text
个人知识库 → 团队知识库 → 公共知识市集 → 商业化平台
```

这个阶段才真正需要完整「超级管理员后台」。

---

## 2. 用户最终看到什么

### 2.1 普通用户

- 可以发布自己的优质笔记；
- 可以生成分享网页；
- 可以克隆别人的优质 Prompt / 解决方案；
- 可以订阅公开知识合集。

### 2.2 团队用户

- 团队空间；
- 团队知识库；
- 成员权限；
- 部门分类；
- 团队 AI 问答；
- 审批发布；
- 团队知识报表。

### 2.3 平台超级管理员

- 管用户；
- 管团队；
- 管订阅；
- 管分享内容；
- 管公共市场；
- 管模型成本；
- 管风控；
- 管系统配置。

## 4. 超级管理员后台详细设计

### 4.1 后台模块

```text
Super Admin
  ├─ Dashboard
  ├─ Users
  ├─ Workspaces
  ├─ Subscriptions
  ├─ Billing
  ├─ Model Providers
  ├─ Prompt Center
  ├─ Public Shares
  ├─ Marketplace
  ├─ Moderation
  ├─ Reports
  ├─ Audit Logs
  ├─ Jobs / Queue
  ├─ Storage
  ├─ Feature Flags
  └─ System Settings
```

### 4.2 Dashboard 指标

- 今日新增用户；
- 今日活跃用户；
- 今日新增笔记；
- 今日模型调用量；
- 今日 embedding 数量；
- 今日分享数；
- 付费转化率；
- MRR；
- 存储用量；
- 失败任务数。

### 4.3 用户管理

功能：

- 搜索用户；
- 查看用户详情；
- 禁用/启用用户；
- 查看用户套餐；
- 查看用户工作区；
- 查看用户用量；
- 重置用户 2FA，可选；
- 数据导出请求；
- 数据删除请求。

注意：

> 超级管理员不应该默认能直接查看用户私密笔记内容，除非用户授权或企业合规要求。隐私是产品核心。

### 4.4 租户/团队管理

功能：

- 创建/禁用团队；
- 查看团队成员；
- 查看团队套餐；
- 查看团队存储用量；
- 查看团队模型用量；
- 处理企业客户配置；
- 管理企业 SSO。

### 4.5 模型供应商管理

配置：

```text
OpenAI-compatible provider
Claude provider
Gemini provider
DeepSeek provider
Ollama local，不在云端后台管理
自建模型 provider
```

字段：

```text
provider_name
base_url
api_key_secret_ref
default_chat_model
default_embedding_model
rate_limit
cost_per_1k_tokens
enabled
```

### 4.6 Prompt Center

管理系统 Prompt：

- 整理笔记 Prompt；
- 分类 Prompt；
- 标签 Prompt；
- Bugfix 模板 Prompt；
- PRD 模板 Prompt；
- RAG 回答 Prompt；
- 周报 Prompt。

需要版本控制：

```text
prompt_id
version
content
created_by
enabled
rollback
ab_test_group
```

### 4.7 内容审核

审核对象：

- 公开分享页；
- 市场 Prompt；
- 市场解决方案；
- 评论；
- 举报内容。

状态：

```text
pending
approved
rejected
hidden
reported
```

### 4.8 功能开关

例如：

```text
enable_browser_auto_capture
enable_public_marketplace
enable_team_rag
enable_mobile_app
enable_local_encryption
enable_mcp
```

## 6. 开发实施步骤

### 6.1 创建后台应用

```bash
cd apps
pnpm create next-app web-admin
```

安装：

```bash
pnpm add @tanstack/react-query zod react-hook-form
pnpm add lucide-react recharts
pnpm add clsx tailwind-merge
```

页面结构：

```text
apps/web-admin/src/app/
  login/
  dashboard/
  users/
  workspaces/
  subscriptions/
  billing/
  model-providers/
  prompts/
  shares/
  marketplace/
  moderation/
  audit-logs/
  jobs/
  settings/
```

### 6.2 后端新增 admin API

```text
GET /admin/users
GET /admin/users/:id
PATCH /admin/users/:id/status

GET /admin/workspaces
GET /admin/workspaces/:id

GET /admin/subscriptions
GET /admin/billing/orders

GET /admin/model-providers
POST /admin/model-providers
PATCH /admin/model-providers/:id

GET /admin/prompts
POST /admin/prompts
POST /admin/prompts/:id/publish

GET /admin/moderation/items
POST /admin/moderation/items/:id/approve
POST /admin/moderation/items/:id/reject

GET /admin/audit-logs
GET /admin/jobs
```

### 6.3 增加审计日志

```sql
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY,
  actor_user_id UUID,
  actor_role TEXT,
  action TEXT NOT NULL,
  resource_type TEXT NOT NULL,
  resource_id TEXT,
  metadata JSONB,
  ip TEXT,
  user_agent TEXT,
  created_at TIMESTAMP NOT NULL
);
```

所有管理员操作必须写审计日志。

## 7. 商业化套餐建议

| 套餐 | 用户 | 能力 |
|---|---|---|
| Free | 个人体验 | 本地知识库、少量 AI 整理、基础导出 |
| Pro | 重度个人用户 | 无限本地笔记、RAG、浏览器插件、CLI、更多导出 |
| Team | 小团队 | 团队知识库、成员权限、团队 RAG |
| Enterprise | 企业 | 私有化部署、SSO、审计、管理员控制 |
