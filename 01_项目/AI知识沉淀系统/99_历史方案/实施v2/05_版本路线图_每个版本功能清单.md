
# 05. 版本路线图：每个版本功能清单

## 总体原则

新版路线图要围绕“知识仓库客户端”展开，而不是围绕“导入工具”展开。

正确顺序：

```text
V0.1 先做知识仓库客户端主体验
V0.2 再增强知识库 AI 问答
V0.3 再做浏览器插件采集
V0.4 再做程序员 CLI / IDE / MCP
V1.0 做完整个人版
V2.0 做多端同步和团队雏形
V3.0 做社区、商业化、超级管理员
```

---

# V0.1：知识仓库客户端基础版

## 目标

> 做出真正的桌面知识库，而不是导入工具。

用户打开客户端后，能管理自己的知识仓库，并在右侧和 AI 对当前笔记对话。

## 必做清单

### 主界面

- [ ] 三栏布局；
- [ ] 顶部全局搜索栏；
- [ ] 左侧知识导航；
- [ ] 中间笔记列表；
- [ ] 中间笔记详情；
- [ ] 右侧 AI 对话栏；
- [ ] 设置入口。

### 笔记系统

- [ ] 新建笔记；
- [ ] 编辑笔记；
- [ ] 保存笔记；
- [ ] 删除笔记；
- [ ] Markdown 渲染；
- [ ] Markdown 编辑；
- [ ] 笔记状态；
- [ ] 分类；
- [ ] 标签；
- [ ] 收藏。

### AI 能力

- [ ] 模型配置；
- [ ] OpenAI-compatible 模型接入；
- [ ] Ollama 接入；
- [ ] 右侧普通对话；
- [ ] 基于当前笔记对话；
- [ ] 总结当前笔记；
- [ ] AI 回答追加到当前笔记。

### 导入和整理

- [ ] 手动粘贴 AI 对话；
- [ ] 保存原始记录；
- [ ] AI 整理为结构化笔记；
- [ ] 用户确认入库。

### 搜索和导出

- [ ] 标题搜索；
- [ ] 正文关键词搜索；
- [ ] 标签过滤；
- [ ] 分类过滤；
- [ ] Markdown 导出；
- [ ] HTML 导出。
