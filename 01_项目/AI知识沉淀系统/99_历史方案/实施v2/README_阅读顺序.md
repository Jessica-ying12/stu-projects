
# AI 知识仓库客户端：新版规划设计阅读顺序

这组文档是根据新的产品理解重新整理的：

> 这个产品的核心不是“导入 AI 对话”，而是一个可以长期打开使用的 **AI 个人知识仓库客户端**。  
> 用户可以在里面查看、编辑、组织自己的知识，并通过右侧 AI 对话栏对知识进行再次提问、学习、总结和复用。

建议阅读顺序：

1. `00_产品重新定位_它到底是什么.md`
2. `01_桌面客户端主页面详细设计.md`
3. `02_右侧AI对话侧边栏_模型接入_知识追问.md`
4. `03_知识仓库功能模块_笔记_分类_标签_模板_学习.md`
5. `04_程序员使用方式_CLI_IDE_MCP.md`
6. `05_版本路线图_每个版本功能清单.md`
7. `06_V0.1实施步骤_从创建项目到主界面.md`
8. `07_数据模型_API_本地架构.md`

最重要的重新定位：

```text
知识仓库是主体
AI 对话是侧边栏
导入采集是入口
模型接入是基础能力
RAG 问答是核心智能能力
CLI / IDE / 浏览器插件是扩展入口
```
