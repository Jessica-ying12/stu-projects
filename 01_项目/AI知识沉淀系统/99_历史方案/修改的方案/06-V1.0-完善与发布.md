## 需求拆分

### 需求 1.0.1：隐私保护 - 敏感信息脱敏

**描述：** 自动识别并脱敏对话中的敏感信息

**验收标准：**
- 自动识别：API Key、手机号、身份证号、邮箱、密码、Token
- 在笔记中自动替换为占位符（如 `[API_KEY_***]`）
- 原始记录保留完整内容（加密存储）
- 用户可配置脱敏规则
- 可手动标记敏感内容

**具体步骤：**
1. 创建 `electron/services/privacy/detector.ts` - 敏感信息检测
2. 创建 `electron/services/privacy/masker.ts` - 脱敏处理
3. 实现正则规则集（各类敏感信息模式）
4. 在笔记生成流程中添加脱敏步骤
5. 创建 `src/pages/PrivacySettingsPage.tsx` - 隐私设置
6. 实现自定义脱敏规则

**检测规则示例：**
```typescript
const patterns = {
  apiKey: /(?:sk|pk|api[_-]?key)[_-]?[a-zA-Z0-9]{20,}/gi,
  phone: /1[3-9]\d{9}/g,
  idCard: /\d{17}[\dXx]/g,
  email: /[\w.-]+@[\w.-]+\.\w+/g,
  token: /(?:token|bearer)\s*[:=]\s*[a-zA-Z0-9._-]{20,}/gi,
  password: /(?:password|passwd|pwd)\s*[:=]\s*\S+/gi,
};
```

**描述：** 对敏感数据进行加密存储

**验收标准：**

- 原始对话内容可选加密存储
- 数据库文件可设置密码保护

**具体步骤：**
1. 创建 `electron/services/privacy/encryption.ts`
2. 使用 Electron `safeStorage` API 加密 API Key
3. 实现数据库加密选项（`better-sqlite3` + `sqlcipher`）
4. 添加应用锁屏功能（可选）
5. 在设置中添加安全选项

### 需求 1.0.5：性能优化

**描述：** 确保应用在大数据量下仍然流畅

**验收标准：**
- 1000+ 条对话时列表滚动流畅
- 搜索响应 < 300ms
- 应用启动时间 < 3s
- 内存占用 < 300MB
- 后台采集不影响前台操作

**具体步骤：**
1. 列表虚拟滚动（`@tanstack/react-virtual`）
2. 数据库查询优化（添加索引、分页）
3. 图片/大文件懒加载
4. 主进程/渲染进程任务分离
5. 减少不必要的重渲染（React.memo、useMemo）
6. Electron 启动优化（延迟加载非关键模块）
7. 性能测试与基准

### 需求 1.0.7：应用打包与发布

**描述：** 打包为 macOS 应用，可安装使用

**验收标准：**
- 打包为 .dmg 安装包
- 应用图标正确
- 应用签名（开发者证书，可选）
- 自动更新检查（可选）
- README 和使用说明

**具体步骤：**
1. 配置 `electron-builder` 打包选项
2. 设计应用图标（1024x1024 PNG → icns）
3. 配置 macOS 相关设置（entitlements、category）
4. 测试打包产物
5. 配置自动更新（electron-updater，可选）
6. 编写 README

**electron-builder 配置：**
```json
{
  "build": {
    "appId": "com.aimemo.app",
    "productName": "AIMemo",
    "mac": {
      "category": "public.app-category.productivity",
      "target": ["dmg", "zip"],
      "icon": "resources/icon.icns"
    },
    "directories": {
      "output": "dist"
    }
  }
}
```
