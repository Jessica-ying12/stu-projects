
# 11. V3.0 商业化、社区与超级管理员

## 1. V3.0 目标

V3.0 是平台化和商业化阶段。

方向：

```text
个人知识库
  ↓
团队知识库
  ↓
优质知识分享
  ↓
公共知识市集
  ↓
订阅商业化
```

---

## 2. 社区和知识市集

功能：

- [ ] 一键生成分享页；
- [ ] 公开 Prompt；
- [ ] 公开问题解决方案；
- [ ] 一键克隆到我的知识库；
- [ ] 收藏；
- [ ] 点赞；
- [ ] 评论；
- [ ] 举报；
- [ ] 审核。

---

## 3. 商业化

套餐：

```text
Free：本地基础功能
Pro：RAG、CLI、浏览器插件、更多模型配置
Team：团队知识库、权限、团队 RAG
Enterprise：私有化、SSO、审计、合规
```

功能：

- [ ] 订阅；
- [ ] 支付；
- [ ] 发票；
- [ ] 用量限制；
- [ ] 模型调用成本统计；
- [ ] 套餐升级降级。

---

## 4. 超级管理员后台

模块：

```text
Dashboard
Users
Workspaces
Subscriptions
Billing
Model Providers
Prompt Center
Public Shares
Marketplace
Moderation
Reports
Audit Logs
Jobs
Storage
Feature Flags
System Settings
```

### 4.1 用户管理

- 搜索用户；
- 禁用/启用；
- 查看套餐；
- 查看用量；
- 查看设备；
- 数据导出请求；
- 数据删除请求。

注意：

```text
超级管理员不应该默认查看用户私密笔记内容。
```

### 4.2 模型管理

- 模型供应商；
- Base URL；
- API Key Secret；
- 默认模型；
- 价格；
- 限流；
- 是否启用。

### 4.3 Prompt Center

管理系统 Prompt：

```text
整理笔记 Prompt
分类 Prompt
标签 Prompt
Bugfix 模板 Prompt
RAG 回答 Prompt
周报 Prompt
```

需要版本控制和回滚。

### 4.4 审计日志

所有管理员操作必须记录：

```text
操作者
动作
资源
IP
时间
变更内容
```

---

## 5. 验收标准

- [ ] 用户可以分享知识；
- [ ] 其他用户可以克隆；
- [ ] 内容可审核；
- [ ] 订阅可用；
- [ ] 超级管理员可管理用户和团队；
- [ ] 管理员操作有审计日志；
- [ ] 平台方能看到运营数据。
