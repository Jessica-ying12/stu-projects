# 07. V2.0 多端同步、云端账号、团队雏形

## 1. 版本目标

V2.0 从纯本地个人工具升级为可多端同步的产品。

目标：

```text
用户可以在多台电脑之间同步知识库
用户可以用账号登录
用户可以选择是否上传云端
用户可以创建小团队共享部分知识
```

## 4. 云端架构

```text
Desktop / Web / Mobile
      ↓
API Gateway
      ↓
Auth Service
      ↓
Knowledge API
      ↓
PostgreSQL + pgvector
      ↓
Object Storage
      ↓
Queue Worker
```

---

## 5. 推荐云端技术选型

| 模块 | 推荐 |
|---|---|
| Web 前端 | Next.js |
| 后端 | NestJS 或 FastAPI |
| 数据库 | PostgreSQL |
| 向量 | pgvector |
| 文件 | S3 兼容对象存储 |
| 队列 | Redis + BullMQ |
| 鉴权 | Auth.js / Lucia / 自研 JWT |
| 部署 | Docker + Fly.io / Render / AWS / 阿里云 |
| 后台 UI | Next.js + shadcn/ui |

如果你想保持 Rust 技术栈：

| 模块 | Rust 方案 |
|---|---|
| 后端 | Axum |
| 数据库 | sqlx + PostgreSQL |
| 队列 | Redis / NATS |
| 管理后台 | Next.js 或 React |

## 6. 数据库设计新增

### 6.1 users

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  password_hash TEXT,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 6.2 workspaces

```sql
CREATE TABLE workspaces (
  id UUID PRIMARY KEY,
  name TEXT NOT NULL,
  owner_id UUID NOT NULL,
  plan TEXT NOT NULL,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 6.3 workspace_members

```sql
CREATE TABLE workspace_members (
  workspace_id UUID NOT NULL,
  user_id UUID NOT NULL,
  role TEXT NOT NULL, -- owner, admin, member, viewer
  created_at TIMESTAMP NOT NULL,
  PRIMARY KEY(workspace_id, user_id)
);
```

### 6.4 sync_events

```sql
CREATE TABLE sync_events (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL,
  device_id TEXT NOT NULL,
  entity_type TEXT NOT NULL,
  entity_id TEXT NOT NULL,
  operation TEXT NOT NULL,
  payload_json JSONB NOT NULL,
  created_at TIMESTAMP NOT NULL
);
```

## 7. 同步设计

### 7.1 同步原则

- 本地仍然是主体验；
- 云端只是可选同步层；
- 不强制上传；
- 同步前可以脱敏；
- 冲突不能静默覆盖。

### 7.2 同步状态

```text
local_only
pending_upload
synced
conflict
failed
```

### 7.3 冲突处理

冲突场景：

```text
电脑 A 修改了笔记
电脑 B 离线也修改了同一笔记
两台设备后来同时同步
```

处理方式：

- 自动保留两个版本；
- 标记 conflict；
- 用户选择合并；
- AI 辅助合并。

## 8. 开发实施步骤

### 8.1 创建云端项目

```bash
mkdir apps/api
cd apps/api
pnpm init
```

如果使用 NestJS：

```bash
pnpm add @nestjs/core @nestjs/common @nestjs/platform-express
pnpm add prisma @prisma/client
pnpm add jsonwebtoken bcrypt
```

如果使用 FastAPI：

```bash
mkdir apps/api-python
cd apps/api-python
python -m venv .venv
pip install fastapi uvicorn sqlalchemy psycopg[binary] pydantic
```

### 8.2 创建 Web 端

```bash
cd apps
pnpm create next-app web
```

页面：

```text
/login
/dashboard
/notes
/ask
/settings
/workspaces
/admin
```

### 8.3 桌面端增加登录

新增页面：

```text
登录页
同步设置页
设备管理页
冲突解决页
```

### 8.4 创建同步 Worker

Worker 职责：

- 处理上传事件；
- 写入云端；
- 生成云端 embedding；
- 处理冲突；
- 推送同步状态。
