
# 07. V0.3 Codex 会话采集、IDE 插件、MCP

## 1. V0.3 目标

V0.1/V0.2 解决“查知识”和“给 Codex 上下文”。  
V0.3 要解决“自动沉淀 Codex 工作过程”。

目标：

```text
Codex 会话可以被采集
Git diff 可以被记录
会话可以整理成 Bug 修复 / 技术方案笔记
AI 编程工具可以通过 MCP 调用知识库
VS Code / Cursor 可以保存代码上下文
```

## 3. `aimem run codex` 设计

### 3.1 使用方式

```bash
aimem run codex
```

或者：

```bash
aimem run -- codex --some-arg
```

### 3.2 记录内容

```json
{
  "command": "codex",
  "cwd": "/Users/sylvia/project/app",
  "gitBranch": "main",
  "gitDiffBefore": "...",
  "transcript": "...",
  "gitDiffAfter": "...",
  "changedFiles": ["src/auth.ts"],
  "startedAt": "...",
  "endedAt": "..."
}
```

### 3.3 技术实现

推荐：

```text
Rust portable-pty 捕获交互式终端
git 命令获取 diff
本地 API 保存 session
```

注意：交互式 CLI 捕获复杂，V0.3 再做，不要放进 V0.1。

## 5. MCP Server 设计

启动：

```bash
aimem mcp serve
```

工具：

```text
knowledge_search(query, project?, tags?, limit?)
knowledge_get(note_id)
knowledge_ask(query, scope?, project?)
knowledge_create_note(title, body_md, tags?, project?)
project_context_get(cwd)
recent_bugfix_notes(project?, limit?)
```

使用场景：

```text
在 AI 编程助手里说：
“先查我的知识库，看看以前有没有解决过类似登录失败。”
```
