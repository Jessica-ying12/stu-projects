
# 08. V0.4 浏览器插件采集网页 AI 对话

## 1. V0.4 目标

V0.4 面向更广泛的 AI 使用场景。

目标：

```text
把 ChatGPT / Claude / Gemini 等网页 AI 对话采集进桌面知识仓库。
```

这个版本放在 Codex 工作流之后，因为你的第一需求是命令行开发工作流。

---

---

## 3. 插件架构

```text
网页 DOM
  ↓ content script
adapter 提取对话
  ↓
background service worker
  ↓
localhost API 127.0.0.1:37891
  ↓
桌面客户端待整理区
```

---

## 4. Adapter 接口

```ts
export interface WebAIAdapter {
  provider: string
  matchUrl(url: string): boolean
  extractConversation(): CapturedConversation | null
}
```

数据：

```ts
export type CapturedConversation = {
  sourceType: 'browser'
  sourceName: string
  title: string
  url: string
  capturedAt: string
  messages: Array<{
    role: 'user' | 'assistant'
    content: string
    seq: number
  }>
}
```

## 5. 实施步骤

```bash
cd apps
pnpm dlx wxt@latest init browser-extension
```

目录：

```text
apps/browser-extension/
  entrypoints/
    background.ts
    content.ts
    popup/App.tsx
  src/
    adapters/
      chatgpt.ts
      claude.ts
      gemini.ts
    api/localClient.ts
    storage/queue.ts
```
