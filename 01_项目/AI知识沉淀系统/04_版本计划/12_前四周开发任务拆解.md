## 4 周结束时必须能做到

```bash
aimem search "登录失败"
aimem ask "我之前怎么解决登录失败？"
aimem context "登录失败 cookie token" --out AIMEM_CONTEXT.md
codex "参考上下文排查当前项目" < AIMEM_CONTEXT.md
pbpaste | aimem save --stdin --type codex
```

客户端必须能：

```text
查看保存的笔记
编辑 Codex 相关笔记
右侧 AI 追问当前笔记
导出 Markdown
```
