# AI 对话知识沉淀系统 - 项目总览与版本规划

## 项目名称

**AIMemo** (暂定)

## 一句话定位

让每一次 AI 对话，都沉淀成你的个人知识资产。

---

## 技术栈选型

| 层级      | 技术                             | 理由                                                 |
| ------- | ------------------------------ | -------------------------------------------------- |
| 桌面端     | Electron + React + TypeScript  | 跨平台、生态成熟、前端技能可复用                                   |
| 后端/本地服务 | Node.js (内嵌于 Electron)         | 与前端统一语言，减少上下文切换                                    |
| 本地数据库   | SQLite (better-sqlite3)        | 轻量、无需额外服务、适合本地优先                                   |
| 全文搜索    | SQLite FTS5                    | 内置于 SQLite，无需额外依赖                                  |
| 向量搜索    | sqlite-vss 或本地 embedding       | 后期 RAG 问答用                                         |
| AI 工具监控 | Node.js chokidar + 日志解析        | 监控 Claude Code / Codex / Cursor / Kiro / Trea 对话文件 |
| AI 整理   | OpenAI API / Claude API / 本地模型 | 对话整理、分类、打标签                                        |
| 样式      | Tailwind CSS                   | 快速开发                                               |
| 状态管理    | Zustand                        | 轻量简洁                                               |
| 构建工具    | Vite + electron-builder        | 快速 HMR + 打包                                        |

---

## 版本规划总览

### V0.1 - 基础骨架 (Week 1-2)

**目标：** 项目跑起来，能手动导入对话并展示

- 项目初始化 (Electron + React + TypeScript)
- SQLite 数据库设计与初始化
- 手动导入对话（粘贴/文件导入）
- 对话列表展示
- 对话详情查看
- 基础搜索

### V0.2 - AI 工具自动采集 (Week 3-4)

**目标：** 自动捕获 Claude Code、Codex、Cursor、Kiro、Trea 的对话

- 通用采集框架（BaseCollector 抽象）
- 工具自动发现（检测已安装的 AI 工具）
- Claude Code 对话文件监控与解析
- Codex 对话文件监控与解析
- Cursor 对话采集
- Kiro 对话采集
- Trea 对话采集
- 后台常驻服务（守护进程）
- 新对话实时通知
- 采集状态面板

### V0.3 - AI 智能整理 (Week 5-6)

**目标：** 对话自动变成结构化知识笔记

- 接入大模型 API（Claude/OpenAI）
- 自动提取标题和摘要
- 自动分类和打标签
- 自动生成结构化笔记（按模板）
- 原始记录与知识笔记分离展示

### V0.4 - 知识管理增强 (Week 7-8)

**目标：** 完善知识库管理能力

- 笔记手动编辑（Markdown 编辑器）
- 自定义分类和标签
- 笔记状态流转（待整理→已整理→已确认→已归档）
- 知识去重提示
- 多格式导出（Markdown / HTML / PDF）

### V0.5 - 知识库问答 (Week 9-10)

**目标：** 对自己的知识库进行 RAG 问答

- 本地 Embedding 生成
- 向量存储与检索
- RAG 问答界面
- 相关笔记推荐
- 每日/每周知识回顾

### V1.0 - 完善与发布 (Week 11-12)

**目标：** 产品化打磨，可日常使用

- 隐私保护（敏感信息脱敏）
- 数据备份与恢复
- 设置面板（API Key、监控路径、自动化开关）
- 性能优化
- 打包发布（macOS DMG）

## 项目目录结构（预期）

```
aimemo/
├── electron/              # Electron 主进程
│   ├── main.ts
│   ├── preload.ts
│   └── services/          # 后台服务
│       ├── collector/     # 采集服务
│       ├── processor/     # AI 整理服务
│       └── database/      # 数据库服务
├── src/                   # React 渲染进程
│   ├── components/
│   ├── pages/
│   ├── stores/
│   ├── hooks/
│   └── utils/
├── shared/                # 主进程/渲染进程共享类型
├── scripts/               # 构建脚本
├── resources/             # 应用图标等资源
└── data/                  # 本地数据目录（运行时）
    ├── db/
    ├── raw/               # 原始对话
    └── notes/             # 整理后笔记
```
