
# 05. V0.1 开发者自用 MVP：桌面客户端 + CLI 基础

## 1. V0.1 目标

V0.1 的目标是你自己能每天用。

必须打通两条链路：

### 链路 A：桌面客户端

```text
打开客户端 → 管理笔记 → 当前笔记 AI 问答 → 保存 AI 回答
```

### 链路 B：命令行 Codex 工作流

```text
终端 aimem search / ask / context → 给 Codex 使用 → 保存结果为笔记
```

## 4. 创建项目

```bash
mkdir ai-knowledge-workspace
cd ai-knowledge-workspace
git init
pnpm init
```

创建 workspace：

```yaml
# pnpm-workspace.yaml
packages:
  - "apps/*"
  - "packages/*"
```

目录：

```bash
mkdir -p apps packages crates migrations docs scripts
```

## 5. 创建桌面客户端

```bash
cd apps
pnpm create tauri-app desktop
```

选择：

```text
React
TypeScript
pnpm
```

安装依赖：

```bash
cd desktop
pnpm add react-router-dom zustand @tanstack/react-query
pnpm add react-markdown remark-gfm lucide-react date-fns
pnpm add clsx tailwind-merge
pnpm add -D tailwindcss postcss autoprefixer
pnpm exec tailwindcss init -p
```

启动：

```bash
pnpm tauri dev
```

## 8. 创建 CLI

```bash
cd crates
cargo new aimem-cli --bin
```

`Cargo.toml` 依赖：

```toml
[dependencies]
clap = { version = "4", features = ["derive"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
tokio = { version = "1", features = ["full"] }
reqwest = { version = "0.12", features = ["json"] }
anyhow = "1"
colored = "2"
comfy-table = "7"
arboard = "3"
```

命令结构：

```rust
#[derive(Subcommand)]
pub enum Commands {
    Status,
    Search { query: String, #[arg(long)] json: bool },
    Show { note_id: String, #[arg(long)] copy: bool, #[arg(long)] json: bool },
    Ask { query: String, #[arg(long)] format: Option<String> },
    Context { query: String, #[arg(long)] out: Option<String> },
    Import { file: String, #[arg(long)] r#type: Option<String> },
    Save { #[arg(long)] stdin: bool, #[arg(long)] title: Option<String> },
}
```
