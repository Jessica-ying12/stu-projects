# 05. V0.4 程序员增强版：CLI、IDE、MCP

## 1. 版本目标

V0.4 专门服务程序员，让知识库进入命令行、IDE 和 AI 编程工具。

目标：

```text
程序员可以在终端搜索知识库
程序员可以把知识库内容传给 Codex / Claude Code
程序员可以采集终端 AI 对话
程序员可以在 VS Code / Cursor 里保存代码修复过程
程序员的 AI 编程工具可以通过 MCP 调用知识库
```

---

## 2. 程序员最终看到什么

安装桌面客户端后，额外安装 CLI：

```bash
aimem
```

常用命令：

```bash
aimem search "登录失败"
aimem show note_123
aimem ask "我之前怎么解决 React hydration 错误？"
aimem run codex
aimem mcp serve
aimem import ./debug-notes.md
aimem export note_123 --format md
```

VS Code / Cursor 中出现命令：

```text
AI Memory: Save Selected Code Explanation
AI Memory: Save Current Error
AI Memory: Generate Bugfix Note
AI Memory: Search Knowledge Base
AI Memory: Attach Git Diff
```

## 4. CLI 详细设计

### 4.1 命令结构

```bash
aimem <command> [options]
```

命令：

```text
search      搜索知识库
show        查看笔记
ask         对知识库提问
import      导入文件/文本
export      导出笔记
run         包装运行 AI CLI 并采集会话
mcp         启动 MCP 服务
config      管理配置
status      查看本地服务状态
doctor      检查环境
```

### 4.2 search

```bash
aimem search "redis 缓存击穿"
aimem search "登录失败" --type bugfix
aimem search "小红书" --tag 运营 --from 2026-05-01
aimem search "OAuth" --json
```

输出示例：

```text
[1] note_a1 登录失败排查流程
    类型：bugfix
    标签：#auth #cookie #debug
    摘要：记录 token、cookie、401 的排查流程。

[2] note_b2 OAuth 回调失败问题
    类型：bugfix
    标签：#OAuth #callback
```

### 4.3 show

```bash
aimem show note_a1
aimem show note_a1 --plain
aimem show note_a1 --json
aimem show note_a1 --copy
```

### 4.4 ask

```bash
aimem ask "我之前怎么解决 Next.js hydration 错误？"
aimem ask "整理我之前的登录失败排查经验" --format md
aimem ask "找出最近一个月关于 Excel 的技巧" --from 2026-05-01
```

### 4.5 和其他 AI CLI 组合

```bash
aimem ask "找出我之前解决登录失败的经验" --format md > context.md
codex "根据 context.md，帮我排查当前项目" < context.md
```

或者：

```bash
aimem show note_a1 --plain | claude "把这条经验应用到当前项目"
```

## 5. CLI 开发实施步骤

### 5.1 创建 Rust CLI 项目

```bash
cd ai-memory-hub/crates
cargo new aimem-cli --bin
cd aimem-cli
```

### 5.2 添加依赖

`Cargo.toml`：

```toml
[dependencies]
clap = { version = "4", features = ["derive"] }
serde = { version = "1", features = ["derive"] }
serde_json = "1"
tokio = { version = "1", features = ["full"] }
reqwest = { version = "0.12", features = ["json"] }
anyhow = "1"
colored = "2"
```

### 5.3 定义命令

```rust
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "aimem")]
pub struct Cli {
    #[command(subcommand)]
    pub command: Commands,
}

#[derive(Subcommand)]
pub enum Commands {
    Search { query: String, #[arg(long)] json: bool },
    Show { note_id: String, #[arg(long)] json: bool, #[arg(long)] copy: bool },
    Ask { query: String, #[arg(long)] format: Option<String> },
    Import { path: String },
    Export { note_id: String, #[arg(long)] format: String, #[arg(long)] out: Option<String> },
    Run { command: String, args: Vec<String> },
    Mcp { #[command(subcommand)] command: McpCommands },
    Status,
    Config,
}

#[derive(Subcommand)]
pub enum McpCommands {
    Serve,
}
```

### 5.4 调用本地 API

```rust
async fn search(query: &str) -> anyhow::Result<()> {
    let url = format!("http://127.0.0.1:37891/api/search?q={}", query);
    let result = reqwest::get(url).await?.text().await?;
    println!("{}", result);
    Ok(())
}
```

## 7. MCP Server 设计

### 7.1 为什么需要 MCP

CLI 搜索是人主动查；MCP 是让 AI 工具主动查你的知识库。

例如你在 Claude Code 里问：

```text
我这个项目登录失败，先查一下我的个人知识库有没有类似经验。
```

Claude Code 可以调用：

```text
knowledge_search("登录失败")
```

### 7.2 MCP 工具

```text
knowledge_search
  输入：query, filters, limit
  输出：note list

knowledge_get
  输入：note_id
  输出：note markdown

knowledge_ask
  输入：query
  输出：answer with sources

knowledge_create_note
  输入：title, markdown, tags, source
  输出：note_id

project_context_save
  输入：cwd, files, git_diff, problem
  输出：conversation_id
```

### 7.3 MCP 启动

```bash
aimem mcp serve
```
