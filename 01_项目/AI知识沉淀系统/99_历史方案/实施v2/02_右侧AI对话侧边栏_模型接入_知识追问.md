
# 02. 右侧 AI 对话侧边栏、模型接入与知识追问

## 1. 右侧 AI 面板的定位

右侧 AI 面板不是普通聊天窗口。

它应该是：

> 基于当前知识上下文的 AI 学习、追问、总结和复用面板。

用户可以一边看中间的笔记，一边在右侧问：

```text
总结这篇笔记
帮我生成复习题
这和我之前的哪篇笔记有关？
把这篇笔记改成模板
把当前分类下的内容整理成周报
根据我之前的经验，给我一个排查 checklist
```

│ ○ 当前笔记                    │

│ ○ 当前标签                    │

├─────────────────────────────┤
│ 快捷操作：                    │
│ [总结当前笔记]                │
│ [生成复习题]                  │

## 3. 知识范围选择

这是右侧 AI 面板最重要的能力之一。

用户必须能明确告诉 AI：这次回答应该基于哪些知识。

### 3.1 范围选项

```text
选中文字
当前笔记
当前目录
当前标签
搜索结果
最近 7 天
某个项目知识库
全部知识库
不使用知识库
```

### 3.2 每种范围的意义

| 范围 | 用途 |
|---|---|
| 选中文字 | 解释、改写、扩写当前选中内容 |
| 当前笔记 | 总结、提问、生成卡片、提取待办 |
| 当前目录 | 汇总某个主题下的知识 |
| 当前标签 | 根据某个标签聚合知识 |
| 搜索结果 | 对搜索出来的一批笔记继续分析 |
| 最近 7 天 | 做周报、学习回顾 |
| 项目知识库 | 程序员按项目检索经验 |
| 全部知识库 | 查历史问题和长期知识 |
| 不使用知识库 | 普通 AI 聊天 |

## 4. 快捷操作设计

右侧 AI 面板上方应该有快捷按钮。

### 4.1 当前笔记快捷操作

```text
总结当前笔记
解释当前笔记
提取关键结论
生成复习题
生成学习卡片
提取待办事项
改写为模板
生成脑图大纲
找相似笔记
翻译当前笔记
```

### 4.2 当前目录快捷操作

```text
总结当前目录
生成目录知识地图
找出重复笔记
合并相似主题
生成本周学习报告
生成项目知识总结
```

### 4.3 搜索结果快捷操作

```text
总结这些搜索结果
按主题重新分类
生成对比表
提取共性方法
生成一份综合文档
```

## 5. AI 回答必须带来源

AI 不能只说：

```text
你之前是这样解决的……
```

必须带来源：

```text
根据以下知识来源：
1. 《登录失败排查流程》
2. 《OAuth 回调失败问题》
3. 《Cookie SameSite 配置说明》

你的排查清单是：
...
```

来源必须可点击打开。

来源显示字段：

```text
标题
相关片段
相关度
来源类型
创建时间
```

---

## 6. AI 回答写回知识库

每次 AI 回答后，用户可以选择保存结果。

按钮：

```text
插入到当前笔记
追加到当前笔记末尾
替换选中内容
生成新笔记
保存为学习卡片
保存为待办
保存为模板
复制
导出
```

重要原则：

> AI 不能默认修改用户笔记，必须由用户确认。

---

## 7. 对话历史设计

右侧 AI 对话也要保存，但不要和知识笔记混在一起。

建议分为：

```text
AI 对话记录：用户和侧边栏 AI 的交互
知识笔记：用户确认沉淀后的内容
```

AI 对话记录可以被再次整理成笔记。

状态：

```text
临时对话
已保存
已整理为笔记
已丢弃
```

## 8. 模型接入设计

用户需要可以自己接入对话 AI 模型。

### 8.1 模型供应商

支持：

```text
OpenAI-compatible
OpenAI
Claude
Gemini
DeepSeek
通义千问
豆包
智谱
Kimi
Ollama
LM Studio
自定义 API
```

### 8.2 每个模型配置字段

```text
供应商名称
供应商类型
Base URL
API Key
Chat Model
Embedding Model
Rerank Model，可选
是否启用
是否默认
最大上下文长度
请求超时时间
并发限制
备注
```

### 8.3 模型用途要分开

不要只设置一个默认模型。

建议分成：

```text
侧边栏对话模型
知识整理模型
自动分类模型
标签生成模型
Embedding 模型
Rerank 模型
本地隐私处理模型
```

示例：

```text
侧边栏对话：Claude
知识整理：GPT-4.1
Embedding：text-embedding-3-small
本地隐私处理：Ollama qwen2.5
```

---

## 9. 模型设置页面

设置页应该有“模型”模块。

### 9.1 模型列表

```text
模型名称 | 类型 | 用途 | 状态 | 默认 | 操作
OpenAI    | OpenAI-compatible | 整理/问答 | 已连接 | 是 | 编辑
Ollama    | Local             | 隐私处理 | 已连接 | 否 | 编辑
Claude    | Claude            | 问答     | 未连接 | 否 | 编辑
```

### 9.2 添加模型弹窗

字段：

```text
模型供应商类型
显示名称
Base URL
API Key
Chat Model
Embedding Model
测试连接按钮
保存按钮
```

### 9.3 测试连接

测试内容：

```text
1. API Key 是否有效
2. Base URL 是否可访问
3. Chat Model 是否可用
4. Embedding Model 是否可用
5. 返回延迟
```

## 10. 右侧 AI 面板开发优先级

### V0.1 必做

- [ ] 右侧固定 AI 对话栏；
- [ ] 模型选择；
- [ ] 模型配置；
- [ ] 普通聊天；
- [ ] 基于当前笔记问答；
- [ ] 总结当前笔记；
- [ ] 回答复制；
- [ ] 回答追加到当前笔记。

### V0.2 必做

- [ ] 当前目录问答；
- [ ] 当前标签问答；
- [ ] 全库问答；
- [ ] 来源引用；
- [ ] 相似笔记推荐；
- [ ] 保存为学习卡片。

### V1.0 必做

- [ ] 多模型用途配置；
- [ ] AI 回答写回不同位置；
- [ ] 对话历史整理成笔记；
- [ ] 自动生成复习题；
- [ ] 自动生成周报/月报。
