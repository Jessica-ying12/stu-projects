
# 02. 桌面客户端：知识工作台详细设计

## 1. 桌面客户端定位

桌面客户端是整个系统的主界面。

它不是：

```text
导入对话工具
聊天记录查看器
简单 Markdown 编辑器
```

它是：

> 一个本地优先的 AI 知识仓库工作台。

---

## 2. 主布局

采用三栏布局：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 顶部栏：全局搜索 | 新建笔记 | 导入 | CLI 状态 | 当前模型 | 设置           │
├───────────────┬──────────────────────────────────────┬─────────────────────┤
│ 左侧知识导航    │ 中间知识工作区                        │ 右侧 AI 对话栏        │
│               │                                      │                     │
│ 全部笔记        │ 笔记列表 / 笔记详情 / Markdown 编辑器   │ 模型选择              │
│ 最近打开        │                                      │ 知识范围              │
│ Codex 会话      │ 当前笔记：登录失败排查流程              │ 当前笔记              │
│ Bug 修复        │                                      │ 当前目录              │
│ 项目知识        │ ## 问题现象                           │ 全部知识库            │
│ 待整理          │ ## 排查过程                           │                     │
│ 分类            │ ## 解决方案                           │ 快捷操作              │
│ 标签            │                                      │ 对话输入框            │
└───────────────┴──────────────────────────────────────┴─────────────────────┘
```

---

## 3. 顶部栏

顶部栏建议：

```text
Logo | 全局搜索 | 新建 | 导入 | 从剪贴板保存 | CLI: Online | 模型 | 设置
```

### 3.1 对开发者特别重要的入口

增加几个开发者快捷入口：

```text
Codex 会话
Bug 修复
项目知识
从终端导入
复制 CLI 命令
```

顶部显示 CLI 连接状态：

```text
CLI: Online
Local API: 127.0.0.1:37891
MCP: Off / On
```

## 5. 中间知识工作区

中间区域需要支持：

```text
知识首页
笔记列表
笔记详情
Markdown 编辑
Codex 会话详情
项目知识视图
搜索结果
待整理详情
```

### 5.1 知识首页

首页推荐模块：

```text
今日新增
最近 Codex 会话
最近 Bug 修复
待整理记录
常用项目
高频标签
继续学习
```

示例：

```text
今天新增 6 条知识，待整理 2 条

最近 Codex 会话：
- 修复登录失败 cookie 问题
- 重构 FastAPI 鉴权中间件

最近 Bug 修复：
- Next.js hydration error
- SQLite FTS 查询异常
```

### 5.2 笔记详情

笔记顶部元信息：

```text
标题
类型
项目
分类
标签
来源：手动 / Codex / CLI / 浏览器 / IDE
状态
创建时间
更新时间
```

正文支持 Markdown。

### 5.3 开发者笔记模板

#### Bug 修复

```md
# 问题名称

## 问题现象

## 环境信息

## 报错信息

## 排查过程

## 根因分析

## 最终解决方案

## 代码变更

## 验证方式

## 经验沉淀

## 相关命令
```

#### Codex 会话总结

```md
# Codex 会话：标题

## 目标

## 关键问题

## Codex 给出的方案

## 我采纳的方案

## 最终代码变更

## 后续待办

## 可复用经验
```

#### 架构设计

```md
# 架构设计名称

## 背景

## 目标

## 约束

## 方案

## 模块划分

## 数据流

## 风险

## 后续演进
```

## 6. 右侧 AI 对话栏

右侧固定存在。

V0.1 必须支持：

```text
普通聊天
基于当前笔记聊天
总结当前笔记
解释当前报错
生成排查 checklist
把回答追加到当前笔记
```

V0.2 再支持：

```text
当前项目知识问答
当前标签问答
全部知识库问答
带来源引用
```

---

## 7. 导入不是主页面，但入口要顺手

入口：

```text
顶部导入
快捷键 Cmd/Ctrl + Shift + I
从剪贴板保存
CLI aimem import
CLI aimem save --stdin
```

导入内容类型：

```text
AI 对话
Codex 输出
报错堆栈
Markdown 文件
代码片段
终端输出
```
