## 目标

项目跑起来，能手动导入对话并展示在桌面端。

## 环境准备

### 前置要求

```bash
# 确认 Node.js 版本 >= 18
node -v

# 确认 npm 或 pnpm
pnpm -v  # 推荐 pnpm，没有则安装：npm install -g pnpm

# 确认 Git
git -v
```

### 项目初始化

```bash
# 创建项目目录
mkdir aimemo && cd aimemo

# 初始化 package.json
pnpm init

# 安装核心依赖
pnpm add electron electron-builder -D
pnpm add react react-dom
pnpm add -D typescript @types/react @types/react-dom
pnpm add -D vite @vitejs/plugin-react
pnpm add -D electron-vite

# 数据库
pnpm add better-sqlite3
pnpm add -D @types/better-sqlite3

# UI
pnpm add tailwindcss @tailwindcss/vite -D

# 状态管理
pnpm add zustand

# 工具
pnpm add dayjs uuid
pnpm add -D @types/uuid
```

### 需求 0.1.2：数据库设计与初始化

**描述：** 设计 SQLite 数据库表结构，应用启动时自动创建

**验收标准：**
- 应用启动时自动创建数据库文件
- 表结构正确创建
- 支持基本 CRUD 操作

**数据库表设计：**

```sql
-- 对话记录表（原始记录）
CREATE TABLE conversations (
  id TEXT PRIMARY KEY,           -- UUID
  source TEXT NOT NULL,          -- 来源：claude-code / codex / manual / chatgpt
  title TEXT,                    -- 对话标题
  raw_content TEXT NOT NULL,     -- 原始对话内容（JSON）
  summary TEXT,                  -- 摘要
  created_at TEXT NOT NULL,      -- 对话发生时间
  imported_at TEXT NOT NULL,     -- 导入时间
  status TEXT DEFAULT 'pending', -- pending / processed / archived
  metadata TEXT                  -- 额外元数据（JSON）
);

-- 知识笔记表（整理后）
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  conversation_id TEXT,          -- 关联原始对话
  title TEXT NOT NULL,
  content TEXT NOT NULL,         -- Markdown 内容
  category TEXT,                 -- 分类
  status TEXT DEFAULT 'draft',   -- draft / confirmed / archived
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (conversation_id) REFERENCES conversations(id)
);

-- 标签表
CREATE TABLE tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  color TEXT,
  created_at TEXT NOT NULL
);

-- 笔记-标签关联表
CREATE TABLE note_tags (
  note_id TEXT NOT NULL,
  tag_id TEXT NOT NULL,
  PRIMARY KEY (note_id, tag_id),
  FOREIGN KEY (note_id) REFERENCES notes(id),
  FOREIGN KEY (tag_id) REFERENCES tags(id)
);

-- 全文搜索虚拟表
CREATE VIRTUAL TABLE conversations_fts USING fts5(
  title, raw_content, summary,
  content=conversations,
  content_rowid=rowid
);

CREATE VIRTUAL TABLE notes_fts USING fts5(
  title, content,
  content=notes,
  content_rowid=rowid
);
```

**具体步骤：**
1. 创建 `electron/services/database/index.ts` - 数据库连接管理
2. 创建 `electron/services/database/schema.ts` - 表结构定义与迁移
3. 创建 `electron/services/database/conversations.ts` - 对话 CRUD
4. 创建 `electron/services/database/notes.ts` - 笔记 CRUD
5. 创建 `electron/services/database/tags.ts` - 标签 CRUD
6. 在主进程启动时初始化数据库
7. 编写单元测试验证 CRUD

### 需求 0.1.3：IPC 通信层

**描述：** 建立 Electron 主进程与渲染进程的通信桥梁

**验收标准：**
- 渲染进程能调用主进程的数据库操作

- 错误能正确传递到渲染进程

**具体步骤：**
1. 创建 `shared/types.ts` - 共享类型定义
2. 创建 `shared/ipc-channels.ts` - IPC 通道名称常量
3. 在 `electron/preload.ts` 中暴露 API
4. 创建 `electron/ipc-handlers.ts` - 注册所有 IPC 处理器
5. 创建 `src/hooks/useDatabase.ts` - 渲染进程调用封装

**IPC 接口设计：**

```typescript
// shared/types.ts
interface Conversation {
  id: string;
  source: 'claude-code' | 'codex' | 'manual' | 'chatgpt';
  title: string;
  rawContent: Message[];
  summary?: string;
  createdAt: string;
  importedAt: string;
  status: 'pending' | 'processed' | 'archived';
  metadata?: Record<string, unknown>;
}

interface Message {
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp?: string;
}

interface Note {
  id: string;
  conversationId?: string;
  title: string;
  content: string;
  category?: string;
  tags: string[];
  status: 'draft' | 'confirmed' | 'archived';
  createdAt: string;
  updatedAt: string;
}

// IPC 通道
interface IpcApi {
  // 对话
  'conversation:list': (params: ListParams) => Conversation[];
  'conversation:get': (id: string) => Conversation;
  'conversation:create': (data: CreateConversationInput) => Conversation;
  'conversation:delete': (id: string) => void;
  'conversation:search': (query: string) => Conversation[];

  // 笔记
  'note:list': (params: ListParams) => Note[];
  'note:get': (id: string) => Note;
  'note:create': (data: CreateNoteInput) => Note;
  'note:update': (id: string, data: UpdateNoteInput) => Note;
  'note:delete': (id: string) => void;
  'note:search': (query: string) => Note[];
}
```
