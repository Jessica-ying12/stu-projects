# 09. 开发总清单：从零创建项目到发布

## 1. 总体路线

不要一开始做大而全。

正确顺序：

```text
V0.1 桌面客户端手动版
  ↓
V0.2 浏览器插件采集
  ↓
V0.3 RAG 知识库问答
  ↓
V0.4 CLI / IDE / MCP 程序员增强
  ↓
V1.0 完整个人版
  ↓
V2.0 多端同步和团队雏形
  ↓
V3.0 社区、商业化、超级管理员
```

---

## 2. 第一阶段：创建项目

### 2.1 初始化仓库

```bash
mkdir ai-memory-hub
cd ai-memory-hub
git init
pnpm init
```

### 2.2 创建 workspace

`pnpm-workspace.yaml`：

```yaml
packages:
  - "apps/*"
  - "packages/*"
```

### 2.3 创建目录

```bash
mkdir -p apps packages crates docs migrations scripts
```

### 2.4 创建根目录文件

```text
README.md
.gitignore
.env.example
pnpm-workspace.yaml
package.json
```

`.gitignore`：

```gitignore
node_modules
.DS_Store
dist
build
.env
*.log
target
apps/desktop/src-tauri/target
```

- OpenAI-compatible；
- Ollama。

### 4.3 设置字段


## 13. 每个版本的验收门槛

| 版本 | 必须达到 |
|---|---|
| V0.1 | 粘贴对话可生成笔记，可搜索，可导出 |
| V0.2 | 浏览器插件可保存网页 AI 对话 |
| V0.3 | 可对知识库自然语言问答，带来源 |
| V0.4 | CLI 可搜索/调用知识库，MCP 可用 |
| V1.0 | 个人用户可长期使用，支持备份和隐私 |
| V2.0 | 多端同步可用，团队雏形可用 |
| V3.0 | 管理后台、商业化、社区可用 |

---

## 14. 你现在立刻应该做的 10 件事

1. 创建 Git 仓库；
2. 创建 pnpm workspace；
3. 创建 Tauri React 桌面应用；
4. 画 5 个核心页面；
5. 创建 SQLite 数据库；
6. 实现手动导入；
7. 实现保存原始记录；
8. 接入 OpenAI-compatible 模型；
9. 实现生成 Markdown 笔记；
10. 实现搜索和导出。

完成这 10 件事后，你就有一个真正的 MVP。
