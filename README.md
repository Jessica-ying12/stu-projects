# stu-projects · 项目设计与方案文档

> 个人项目的完整设计文档沉淀：从产品愿景、需求分析，到技术方案与版本路线图。

## 关于这个仓库

这里存放的是我从 0 到 1 完整设计一个产品时产出的文档——不只有最终方案，还保留了**方案演进的完整过程**（多次推倒重来的历史版本），真实反映了一个想法如何逐步打磨成型。

## 项目清单

### 🧠 AI 知识沉淀系统

> 面向所有 AI 使用者的「个人知识管理系统（PKMS）」，自动把与各种 AI 工具（Codex、Cursor、浏览器大模型等）的交流内容，整理成可复用、可搜索、可学习、可导出的个人知识库。

#### 文档结构

```
01_项目/AI知识沉淀系统/
├── 01_项目定义/      # 项目愿景、问题定义、目标用户
├── 02_产品设计/      # 产品形态、桌面客户端、CLI、Codex 插件设计
├── 03_技术方案/      # CLI 命令设计、本地架构（数据库/API/服务/MCP）
├── 04_版本计划/      # V0.1 MVP → V3.0 商业化的完整演进路线
└── 99_历史方案/      # 实施 v1 / v2 的完整迭代记录
```

#### 核心亮点

- **完整的产品设计闭环**：愿景 → 定位 → 产品形态 → 技术架构 → 版本规划
- **多端形态设计**：桌面客户端 + CLI 工具 + IDE 插件 + 浏览器插件
- **版本路线清晰**：从「开发者自用 MVP」逐步演进到「多端同步 + 商业化」
- **真实迭代记录**：保留了两轮完整方案重构（实施 v1 → v2）的历史
