# 06. V1.0 完整个人版

## 1. 版本目标

V1.0 是第一个可以正式发布给个人用户使用的版本。

它应该形成完整个人产品闭环：

```text
采集 → 整理 → 分类 → 搜索 → 问答 → 导出 → 回顾 → 备份
```

## 4. V1.0 新增重点功能

### 4.1 每日回顾

每天自动生成：

```md
# 今日 AI 知识回顾

## 今日新增笔记

## 重要问题

## 可复用方法

## 待办事项

## 建议复习
```

### 4.2 每周总结

```md
# 本周 AI 知识总结

## 本周高频主题

## 解决的问题

## 学到的知识

## 可复用模板

## 下周建议
```

### 4.3 自动待办提取

从对话中识别：

```text
我要去调研 xxx
需要修改 xxx
后续补充 xxx
下一步做 xxx
```

生成待办列表。

### 4.4 学习卡片

从学习笔记自动生成：

```text
Q: 什么是 RAG？
A: RAG 是检索增强生成...
```

支持导出 Anki。

## 5. 开发实施步骤

### 5.1 完善导出模块

目录：

```text
packages/exporters/
  src/
    markdown.ts
    html.ts
    pdf.ts
    word.ts
    anki.ts
```

导出接口：

```ts
interface Exporter {
  format: string
  export(note: Note, options: ExportOptions): Promise<ExportResult>
}
```

### 5.2 添加版本历史

新增表：

```sql
CREATE TABLE note_revisions (
  id TEXT PRIMARY KEY,
  note_id TEXT NOT NULL,
  title TEXT NOT NULL,
  body_md TEXT NOT NULL,
  changed_by TEXT,
  change_reason TEXT,
  created_at TEXT NOT NULL
);
```

每次用户保存笔记，创建 revision。

### 5.3 添加待办提取

新增表：

```sql
CREATE TABLE todos (
  id TEXT PRIMARY KEY,
  note_id TEXT,
  title TEXT NOT NULL,
  status TEXT NOT NULL,
  due_at TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

### 5.4 添加回顾任务

本地定时任务：

```text
每天 20:00 生成今日回顾
每周日 20:00 生成每周总结
```

用户也可以手动生成。

### 5.5 添加备份恢复

备份内容：

```text
SQLite 数据库
notes/markdown
attachments
config，不包含明文 API Key
```

备份格式：

```text
ai-memory-backup-2026-05-27.zip
```
