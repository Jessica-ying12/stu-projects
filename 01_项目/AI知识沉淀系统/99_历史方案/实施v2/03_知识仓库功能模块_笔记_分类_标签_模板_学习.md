
# 03. 知识仓库功能模块：笔记、分类、标签、模板、学习

## 1. 知识仓库核心对象

系统中不应该只有“聊天记录”。

至少要有这些对象：

```text
原始记录 Raw Record
知识笔记 Note
分类 Category
标签 Tag
模板 Template
学习卡片 Flashcard
待办 Todo
附件 Attachment
来源 Source
AI 对话 Session
```

---

## 2. 原始记录和知识笔记分离

必须分离。

### 2.1 原始记录

保存完整上下文。

包括：

```text
原始 AI 对话
网页 URL
工具名称
采集时间
用户输入
AI 输出
代码 diff
附件
截图，可选
```

用途：

```text
追溯来源
重新整理
证明笔记来源
保留排错过程
```

### 2.2 知识笔记

保存整理后的结构化内容。

包括：

```text
标题
摘要
正文 Markdown
分类
标签
类型
来源引用
状态
版本历史
```

用途：

```text
阅读
编辑
搜索
问答
导出
复习
复用
```

---

## 3. 笔记状态

推荐状态：

```text
草稿 draft
待确认 pending_confirm
已确认 confirmed
已归档 archived
已删除 deleted
```

流程：

```text
采集原始内容
  ↓
AI 生成草稿笔记
  ↓
用户编辑
  ↓
用户确认
  ↓
进入正式知识库
```

---

## 4. 笔记类型

内置类型：

| 类型 | 说明 |
|---|---|
| 通用问答 | 普通 AI 问答沉淀 |
| Bug 修复 | 报错、排查、修复过程 |
| 学习笔记 | 知识点解释、课程笔记 |
| 产品需求 | PRD、需求分析、用户故事 |
| Prompt 模板 | 提示词和调用模板 |
| 工作文档 | 周报、汇报、邮件、会议总结 |
| 创作内容 | 文案、脚本、标题、选题 |
| 决策记录 | 方案对比、选型、优劣分析 |
| 避坑指南 | 错误经验、注意事项 |
| 操作流程 | SOP、步骤、清单 |

## 5. 笔记模板

系统应内置模板，也允许用户自定义模板。

### 5.1 通用问答模板

```md
# 标题

## 原始问题

## 核心结论

## 详细说明

## 可复用方法

## 相关知识

## 标签
```

### 5.2 Bug 修复模板

```md
# 问题名称

## 问题现象

## 环境信息

## 原因分析

## 排查过程

## 最终解决方案

## 验证方式

## 经验沉淀

## 相关代码 / 文件
```

### 5.3 产品需求模板

```md
# 需求名称

## 背景

## 用户痛点

## 目标用户

## 解决方案

## 用户流程

## 功能清单

## 风险点

## 后续优化
```

### 5.4 学习笔记模板

```md
# 知识点名称

## 简单解释

## 关键概念

## 示例

## 易错点

## 复习问题

## 延伸阅读
```

## 6. 分类系统

分类像文件夹，适合表示知识归属。

建议支持多级分类：

```text
工作
  ├─ 产品
  ├─ 运营
  ├─ 汇报
  └─ 会议

技术
  ├─ 前端
  ├─ 后端
  ├─ 数据库
  ├─ AI
  └─ 工具

学习
  ├─ 课程
  ├─ 英语
  ├─ 论文
  └─ 考试

生活
  ├─ 旅行
  ├─ 健康
  ├─ 购物
  └─ 育儿
```

分类策略：

```text
AI 自动推荐
用户可修改
用户可拖拽移动
笔记可以有主分类
```

## 7. 标签系统

标签用于跨分类索引。

示例：

```text
#Python
#API
#bug
#小红书
#Excel
#PRD
#性能优化
#避坑
#模板
```

标签功能：

- 自动生成；
- 手动添加；
- 合并标签；
- 标签重命名；
- 标签统计；
- 高频标签推荐；
- 按标签问答。

## 8. 学习模块

这部分是产品差异化重点。

用户不是只保存知识，而是要再次学习。

### 8.1 每日回顾

每天自动生成：

```md
# 今日知识回顾

## 今日新增知识

## 今日解决的问题

## 今日高价值结论

## 需要复习的内容

## 建议明天继续学习
```

### 8.2 每周总结

```md
# 本周知识总结

## 本周高频主题

## 本周解决的问题

## 本周可复用模板

## 本周待办事项

## 下周建议
```

### 8.3 学习卡片

支持从笔记生成：

```text
问题
答案
来源笔记
标签
复习次数
下次复习时间
```

可以导出 Anki。

### 8.4 错题本 / 避坑指南

当系统识别到：

```text
报错
失败
怎么修
为什么不对
这里错了
踩坑
```

自动推荐标签：

```text
#错题本
#避坑指南
#Bug修复
```
