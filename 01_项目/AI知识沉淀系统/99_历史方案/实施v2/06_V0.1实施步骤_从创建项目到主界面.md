
# 06. V0.1 实施步骤：从创建项目到主界面

## 1. V0.1 实施目标

V0.1 不是先做导入工具，而是先做桌面知识仓库主体验。

本版本完成后，用户应该可以：

```text
打开桌面客户端
  ↓
看到三栏知识工作台
  ↓
在左侧浏览分类和标签
  ↓
在中间查看、编辑笔记
  ↓
在右侧选择模型并对当前笔记提问
  ↓
把 AI 回答追加到当前笔记
```

---

## 2. 技术选型

推荐：

```text
桌面框架：Tauri 2
前端：React + TypeScript + Vite
UI：Tailwind CSS + shadcn/ui
状态管理：Zustand
请求状态：TanStack Query
数据库：SQLite
后端：Rust
Markdown：react-markdown / Milkdown / TipTap，可先用 Markdown textarea
AI 接口：OpenAI-compatible + Ollama
```

### 11.2 表结构

`migrations/0001_init.sql`：

```sql
CREATE TABLE notes (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  type TEXT NOT NULL,
  category TEXT,
  summary TEXT,
  body_md TEXT NOT NULL,
  status TEXT NOT NULL,
  favorite INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE TABLE tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  type TEXT NOT NULL
);

CREATE TABLE note_tags (
  note_id TEXT NOT NULL,
  tag_id TEXT NOT NULL,
  PRIMARY KEY(note_id, tag_id)
);

CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  parent_id TEXT,
  sort_order INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE conversations (
  id TEXT PRIMARY KEY,
  source_type TEXT NOT NULL,
  source_name TEXT,
  title TEXT,
  url TEXT,
  status TEXT NOT NULL,
  raw_hash TEXT,
  metadata_json TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE TABLE messages (
  id TEXT PRIMARY KEY,
  conversation_id TEXT NOT NULL,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  seq INTEGER NOT NULL,
  metadata_json TEXT,
  created_at TEXT NOT NULL
);

CREATE TABLE note_sources (
  id TEXT PRIMARY KEY,
  note_id TEXT NOT NULL,
  conversation_id TEXT NOT NULL,
  message_id TEXT
);

CREATE TABLE app_settings (
  key TEXT PRIMARY KEY,
  value_json TEXT NOT NULL
);
```

## 14. 当前笔记 AI 问答实现

输入：

```ts
type ChatInput = {
  modelProviderId: string
  scope: 'none' | 'current_note'
  noteId?: string
  messages: Array<{ role: 'user' | 'assistant'; content: string }>
}
```

如果 scope 是 `current_note`，后端拼接：

```text
你是用户的知识库学习助手。
请根据当前笔记回答用户问题。
不要编造笔记中没有的信息。

当前笔记：
{note.title}
{note.body_md}

用户问题：
{question}
```
