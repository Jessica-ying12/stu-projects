# 03. V0.2 浏览器插件采集版

## 1. 版本目标

V0.2 的目标是让采集更低摩擦。

V0.1 需要用户复制粘贴，V0.2 要做到：

```text
用户在 ChatGPT / Claude / Gemini 网页对话
    ↓
点击浏览器插件按钮
    ↓
当前对话自动保存到本地客户端
    ↓
进入待整理队列
```

---

## 2. 用户最终看到什么

用户会安装两个东西：

1. 桌面客户端；
2. 浏览器插件。

浏览器插件表现：

```text
浏览器右上角有插件图标
在 ChatGPT / Claude 页面右侧出现「保存到 AI Memory」按钮
点击后提示：已保存到本地知识库
```

插件弹窗：

```text
AI Memory Hub
----------------
本地客户端：已连接
当前页面：ChatGPT
当前对话：可采集

[保存当前对话]
[保存选中内容]
[打开桌面客户端]
[设置]
```

## 4. 技术架构

```text
Web 页面
  ↓ content script 提取 DOM
browser extension background
  ↓ localhost HTTP / Native Messaging
本地桌面客户端 Ingestion API
  ↓
SQLite conversations/messages
  ↓
待整理队列
```

### 5.2 定义采集数据格式

```ts
export type CapturedConversation = {
  sourceType: 'browser'
  sourceName: string
  title: string
  url: string
  capturedAt: string
  messages: Array<{
    role: 'user' | 'assistant'
    content: string
    seq: number
  }>
  metadata: {
    browser: string
    pageTitle: string
    adapterVersion: string
  }
}
```

### 5.3 定义 Adapter 接口

```ts
export interface WebAIAdapter {
  provider: string
  matchUrl(url: string): boolean
  extractConversation(): CapturedConversation | null
}
```

### 5.4 ChatGPT Adapter 示例

```ts
export const chatgptAdapter: WebAIAdapter = {
  provider: 'ChatGPT',
  matchUrl(url) {
    return url.includes('chatgpt.com') || url.includes('chat.openai.com')
  },
  extractConversation() {
    const title = document.title
    const url = location.href

    // 注意：真实选择器需要持续维护
    const nodes = Array.from(document.querySelectorAll('[data-message-author-role]'))

    const messages = nodes.map((node, index) => {
      const role = node.getAttribute('data-message-author-role') === 'user' ? 'user' : 'assistant'
      return {
        role,
        content: node.textContent?.trim() || '',
        seq: index
      }
    }).filter(m => m.content.length > 0)

    return {
      sourceType: 'browser',
      sourceName: 'ChatGPT',
      title,
      url,
      capturedAt: new Date().toISOString(),
      messages,
      metadata: {
        browser: 'unknown',
        pageTitle: title,
        adapterVersion: '0.1.0'
      }
    }
  }
}
```

### 5.5 本地客户端开放 Ingestion API

桌面客户端启动时开启：

```text
http://127.0.0.1:37891
```

接口：

```http
POST /api/ingest/browser-conversation
```

请求：

```json
{
  "sourceType": "browser",
  "sourceName": "ChatGPT",
  "title": "一次产品方案讨论",
  "url": "https://chatgpt.com/...",
  "messages": []
}
```

### 5.6 插件连接本地客户端

```ts
export async function checkLocalApp() {
  try {
    const res = await fetch('http://127.0.0.1:37891/api/health')
    return res.ok
  } catch {
    return false
  }
}

export async function sendConversation(data: CapturedConversation) {
  const res = await fetch('http://127.0.0.1:37891/api/ingest/browser-conversation', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${await getLocalToken()}`
    },
    body: JSON.stringify(data)
  })

  if (!res.ok) throw new Error('send failed')
  return res.json()
}
```

### 5.7 配对流程

为了安全，插件第一次连接本地客户端需要配对。

流程：

```text
插件点击「连接本地客户端」
    ↓
本地客户端弹窗显示 6 位验证码
    ↓
用户在插件输入验证码
    ↓
本地客户端生成 local token
    ↓
插件保存 token
```

本地 API：

```text
POST /api/pair/start
POST /api/pair/verify
```
