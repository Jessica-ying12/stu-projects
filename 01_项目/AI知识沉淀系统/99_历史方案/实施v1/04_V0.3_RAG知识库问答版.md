# 04. V0.3 RAG 知识库问答版

## 1. 版本目标

V0.3 的目标是让用户可以“问自己的知识库”。

用户不只是搜索关键词，而是可以问：

```text
我之前怎么解决登录失败的问题？
上个月我问过哪些小红书运营技巧？
帮我把最近的产品需求问答整理成 PRD 模板。
我之前让 AI 写过的竞品分析框架在哪里？
```

## 5. 数据结构新增

### 5.1 chunks 表

```sql
CREATE TABLE chunks (
  id TEXT PRIMARY KEY,
  note_id TEXT NOT NULL,
  content TEXT NOT NULL,
  chunk_index INTEGER NOT NULL,
  hash TEXT,
  vector_id TEXT,
  token_count INTEGER,
  created_at TEXT NOT NULL
);
```

### 5.2 embeddings_jobs 表

```sql
CREATE TABLE embedding_jobs (
  id TEXT PRIMARY KEY,
  chunk_id TEXT NOT NULL,
  status TEXT NOT NULL, -- pending, running, done, failed
  error TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

### 5.3 ask_history 表

```sql
CREATE TABLE ask_history (
  id TEXT PRIMARY KEY,
  query TEXT NOT NULL,
  answer TEXT NOT NULL,
  sources_json TEXT,
  created_at TEXT NOT NULL
);
```

## 6. 开发实施步骤

### 6.1 创建 chunk 切分模块

目录：

```text
crates/local-core/src/rag/
  mod.rs
  chunker.rs
  embedder.rs
  retriever.rs
  reranker.rs
  answerer.rs
```

chunk 规则：

```text
每个 chunk 300~800 中文字
按 Markdown 标题优先切分
保留 note_id、标题、标签、来源
```

伪代码：

```rust
pub fn chunk_markdown(note_id: &str, markdown: &str) -> Vec<Chunk> {
    // 1. 按标题切分
    // 2. 太长的段落继续按段落切分
    // 3. 太短的段落合并
    // 4. 生成 hash，避免重复 embedding
}
```

### 6.2 创建 embedding Provider

```rust
pub trait EmbeddingProvider {
    async fn embed(&self, texts: Vec<String>) -> Result<Vec<Vec<f32>>, AppError>;
}
```

OpenAI-compatible 请求：

```json
{
  "model": "text-embedding-3-small",
  "input": ["文本1", "文本2"]
}
```

### 6.3 选择向量库

MVP 可选两种：

#### 方案 A：LanceDB

优点：专门做向量检索，功能更完整。  
缺点：Rust 集成复杂度可能略高。

#### 方案 B：sqlite-vec

优点：和 SQLite 统一，更简单。  
缺点：生态和高级能力较弱。

建议：

```text
如果你想尽快做出来：先用 sqlite-vec 或简单本地向量文件。
如果你想长期扩展：用 LanceDB。
```

### 6.4 混合检索

检索结果结构：

```ts
type RetrievedChunk = {
  chunkId: string
  noteId: string
  title: string
  content: string
  vectorScore?: number
  keywordScore?: number
  finalScore: number
}
```

混合排序：

```text
finalScore = vectorScore * 0.7 + keywordScore * 0.3
```

## 7. 本地命令接口

Tauri command：

```rust
#[tauri::command]
async fn rebuild_index() -> Result<(), String>;

#[tauri::command]
async fn ask_knowledge_base(input: AskInput) -> Result<AskResult, String>;
```

输入：

```ts
type AskInput = {
  query: string
  topK?: number
  filters?: {
    type?: string
    tags?: string[]
    fromDate?: string
    toDate?: string
  }
}
```

输出：

```ts
type AskResult = {
  answer: string
  sources: Array<{
    noteId: string
    title: string
    snippet: string
    score: number
  }>
}
```
