
# 09. V1.0 完整个人版发布清单

## 1. V1.0 目标

V1.0 是可以给个人用户长期使用的版本。

它应该同时适合：

```text
开发者
产品经理
运营
学生
职场人员
创作者
普通 AI 用户
```

---

## 2. 功能清单

- [ ] 稳定桌面客户端；
- [ ] 知识工作台；
- [ ] 笔记编辑；

## 4. 验收标准

- [ ] 新用户 5 分钟内能创建第一条笔记；
- [ ] 开发者 5 分钟内能用 CLI 搜索知识；
- [ ] 用户能配置自己的模型；
- [ ] RAG 回答带来源；
- [ ] 浏览器插件能保存主流 AI 网页对话；
- [ ] Codex 工作流能实际提升开发效率；
- [ ] 数据可备份恢复；
- [ ] 关闭云端也能完整使用。
