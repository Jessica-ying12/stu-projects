
# 10. V2.0 多端同步与团队版

## 1. V2.0 目标

从个人本地工具升级为可选云同步和小团队协作。

原则：

```text
本地优先不变
云同步可选
团队共享可选
隐私优先
```

---

## 2. 功能清单

### 2.1 账号与同步

- [ ] 用户注册登录；
- [ ] 设备管理；
- [ ] 云同步开关；
- [ ] 笔记同步；
- [ ] 原始记录同步，可选；
- [ ] 附件同步；
- [ ] 冲突检测；
- [ ] 冲突合并；
- [ ] 同步日志。

### 2.2 Web 端

- [ ] 登录；
- [ ] 查看知识库；
- [ ] 搜索；
- [ ] RAG 问答；
- [ ] 基础编辑；
- [ ] 导出。

### 2.3 团队

- [ ] Workspace；
- [ ] 邀请成员；
- [ ] 角色权限；
- [ ] 团队知识库；
- [ ] 团队标签；
- [ ] 团队 RAG；
- [ ] 知识共享审批。

---

## 3. 技术选型

```text
Web: Next.js
API: NestJS / FastAPI / Rust Axum
DB: PostgreSQL
Vector: pgvector / Qdrant
Storage: S3 compatible
Queue: Redis + BullMQ / NATS
Auth: Auth.js / Keycloak / custom JWT
```

---

## 4. 同步模型

状态：

```text
local_only
pending_upload
synced
conflict
failed
```

冲突策略：

```text
不覆盖
保留两个版本
用户手动合并
AI 辅助合并
```

---

## 5. 验收标准

- [ ] 两台电脑能同步笔记；
- [ ] 离线修改后能处理冲突；
- [ ] 用户能关闭同步；
- [ ] 团队成员权限生效；
- [ ] 团队知识问答带来源；
- [ ] 不上传时本地功能不受影响。
