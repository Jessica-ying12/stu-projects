# AI 知识沉淀系统：产品与实施文档阅读顺序

这组文档把你的产品拆成「用户最终看到什么」「程序员怎么用」「超级管理员是什么」「每个版本做什么」「每个版本如何实施」。

建议阅读顺序：

1. `00_产品形态_用户端_程序员端_超级管理员.md`
2. `01_总体技术架构_项目结构_数据模型_API.md`
3. `02_V0.1_本地手动版_桌面客户端.md`
4. `03_V0.2_浏览器插件采集版.md`
5. `04_V0.3_RAG知识库问答版.md`
6. `05_V0.4_程序员增强版_CLI_IDE_MCP.md`
7. `06_V1.0_完整个人版.md`
8. `07_V2.0_多端同步_云端账号_团队雏形.md`
9. `08_V3.0_团队社区商业化_超级管理员后台.md`
10. `09_开发总清单_从零创建项目到发布.md`

一句话总结：

> 先做一个跨平台桌面客户端，解决「粘贴 AI 对话 → 自动整理 → 本地搜索 → 导出」；再做浏览器插件；再做 RAG 问答；再做程序员 CLI / IDE / MCP；最后做同步、团队、社区和超级管理员后台。
