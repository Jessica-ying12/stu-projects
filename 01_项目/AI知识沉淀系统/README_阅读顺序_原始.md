
# AI 知识仓库：Codex 开发者优先版完整规划

这版重新按你的真实使用场景整理：

> 你是开发者，经常在命令行使用 Codex。  
> 所以第一阶段不能只做“普通用户桌面客户端”，而要做 **桌面知识仓库客户端 + 开发者 CLI 入口**。  
> 桌面客户端仍然是第一优先级和主界面，但 CLI 必须很早做出来，让你能在终端里搜索、提问、注入知识上下文、采集 Codex 会话。

## 最新路线一句话

```text
先做桌面知识仓库客户端，保证知识可查看、编辑、提问；
同时在 V0.1 就做 aimem CLI，让你在 Codex 命令行工作流中能搜索知识、提问知识库、注入上下文。
```
