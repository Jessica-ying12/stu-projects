# V0.2 - CLI 自动采集

## 目标

自动捕获 Claude Code 和 Codex 的对话记录，无需手动导入。

---

## 背景知识

### Claude Code 对话存储位置

Claude Code 的对话历史存储在：
```
~/.claude/projects/          # 项目级对话
~/.claude/conversations/     # 全局对话（旧版）
```

每个对话是一个 JSON 文件，包含完整的消息列表。

### Codex (OpenAI CLI) 对话存储位置

Codex CLI 的对话存储在：
```
~/.codex/conversations/      # 对话记录
```

> 注意：具体路径可能随版本变化，需要在开发时确认实际路径。

## 需求拆分

### 需求 0.2.1：Claude Code 对话文件发现

**描述：** 扫描并识别 Claude Code 的对话文件

**验收标准：**
- 能找到 `~/.claude/` 下所有对话文件
- 正确解析对话文件的 JSON 结构
- 识别新增的对话文件
- 记录已处理的文件（避免重复导入）

**具体步骤：**
1. 创建 `electron/services/collector/claude-code.ts`
2. 研究 Claude Code 对话文件的实际 JSON 结构
3. 实现文件扫描逻辑（递归遍历目录）
4. 实现 JSON 解析，提取对话消息
5. 创建 `electron/services/database/sync-state.ts` - 记录同步状态
6. 添加数据库表记录已处理文件的路径和修改时间

**新增数据库表：**
```sql
CREATE TABLE sync_state (
  file_path TEXT PRIMARY KEY,
  last_modified TEXT NOT NULL,
  last_synced TEXT NOT NULL,
  source TEXT NOT NULL,
  conversation_id TEXT,
  FOREIGN KEY (conversation_id) REFERENCES conversations(id)
);
```

### 需求 0.2.2：文件监控服务

**描述：** 实时监控对话目录，发现新对话自动导入

**验收标准：**
- 应用启动时开始监控指定目录
- 新文件创建时触发导入
- 文件修改时触发更新（对话追加消息）
- 监控不影响应用性能
- 监控异常时自动恢复

**具体步骤：**
1. 创建 `electron/services/collector/watcher.ts` - 文件监控核心
2. 使用 `chokidar` 库监控目录变化（比原生 fs.watch 更可靠）
3. 实现文件变化事件处理（add / change）
4. 添加防抖处理（文件可能频繁写入）
5. 实现错误恢复机制
6. 创建 `electron/services/collector/index.ts` - 采集服务统一入口

**额外依赖：**
```bash
pnpm add chokidar
```

### 需求 0.2.7：采集配置

**描述：** 用户可配置采集相关参数

**验收标准：**
- 可配置 Claude Code 对话目录路径
- 可配置 Codex 对话目录路径
- 可添加自定义监控路径
- 可设置采集频率（实时/定时）
- 配置持久化存储

**具体步骤：**
1. 创建 `electron/services/config.ts` - 配置管理
2. 创建配置文件存储（`~/.aimemo/config.json`）
3. 创建 `src/pages/SettingsPage.tsx` - 设置页面（采集部分）
4. 创建 `src/components/PathSelector.tsx` - 路径选择组件
5. 实现配置变更后重启监控服务

**配置结构：**
```json
{
  "collector": {
    "enabled": true,
    "sources": {
      "claude-code": {
        "enabled": true,
        "path": "~/.claude/projects",
        "mode": "realtime"
      },
      "codex": {
        "enabled": true,
        "path": "~/.codex/conversations",
        "mode": "realtime"
      }
    },
    "notification": true,
    "scanIntervalMinutes": 5
  }
}
```
