
# 01. 桌面客户端主页面详细设计

## 1. 主页面设计原则

桌面客户端不是“导入工具”，而是“知识工作台”。

主页面必须满足：

1. 用户一打开就能看到自己的知识仓库；
2. 用户可以快速搜索、查看、编辑笔记；
3. AI 对话区必须在侧边栏；
4. AI 可以基于当前笔记、目录、标签或全库回答；
5. AI 回答可以一键写回知识库；
6. 导入、整理、采集只是顶部或侧边栏入口，不是主页面主体。

---

## 2. 推荐整体布局

采用三栏结构：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 顶部栏：全局搜索 | 新建笔记 | 导入 | 当前模型 | 同步状态 | 设置             │
├───────────────┬──────────────────────────────────────┬─────────────────────┤
│ 左侧知识导航    │ 中间知识仓库工作区                    │ 右侧 AI 对话侧边栏    │
│               │                                      │                     │
│ 我的知识库      │ 笔记列表 / 笔记详情 / 编辑器            │ 和当前知识对话         │
│ 最近笔记        │                                      │                     │
│ 待整理          │ 当前打开：登录失败排查流程              │ 模型选择              │
│ 收藏            │                                      │ 知识范围选择           │
│ 标签            │ # 登录失败排查流程                     │ 当前笔记 / 当前目录     │
│ 分类            │                                      │ 全部知识库             │
│ 模板            │ ## 问题现象                           │                     │
│ 回顾            │ ## 原因分析                           │ 用户提问输入框          │
│ 设置            │ ## 解决方案                           │                     │
│               │                                      │ AI 回答 + 来源引用      │
└───────────────┴──────────────────────────────────────┴─────────────────────┘
```

---

## 3. 顶部栏设计

顶部栏用于全局操作。

```text
┌──────────────────────────────────────────────────────────────┐
│ Logo | 全局搜索框 | 新建笔记 | 导入 | AI 模型 | 本地/同步 | 设置 │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 顶部栏功能

| 区域 | 功能 |
|---|---|
| Logo / 产品名 | 返回知识工作台首页 |
| 全局搜索 | 搜索所有笔记、原始对话、标签、附件 |
| 新建笔记 | 新建空白笔记、模板笔记、AI 生成笔记 |
| 导入 | 粘贴 AI 对话、导入文件、导入网页内容 |
| 当前模型 | 显示当前默认 AI 模型，点击可切换 |
| 同步状态 | 本地模式、同步中、已同步、冲突 |
| 设置 | 模型、隐私、数据目录、导出、插件 |

### 3.2 全局搜索体验

搜索框支持：

```text
关键词搜索
语义搜索
标签搜索
分类搜索
时间范围搜索
来源搜索
```

示例输入：

```text
登录失败
#Python
type:bugfix cookie
source:ChatGPT 小红书运营
from:2026-05-01 Excel
```

## 4. 左侧知识导航区

左侧不是普通菜单，而是知识库的目录和智能视图。

### 4.1 左侧结构

```text
我的知识库
├─ 全部笔记
├─ 最近打开
├─ 收藏
├─ 待整理
├─ 已确认
├─ 已归档
├─ 回收站

智能视图
├─ AI 问答沉淀
├─ Bug / 问题修复
├─ 产品需求
├─ 学习笔记
├─ Prompt 模板
├─ 工作总结
├─ 创作内容
├─ 决策记录

分类
├─ 工作
│  ├─ 产品
│  ├─ 运营
│  └─ 汇报
├─ 技术
│  ├─ 前端
│  ├─ 后端
│  ├─ AI
│  └─ 工具
├─ 学习
├─ 生活
└─ 创作

标签
├─ #Python
├─ #API
├─ #Excel
├─ #小红书
├─ #Bug
├─ #PRD

学习
├─ 每日回顾
├─ 每周总结
├─ 学习卡片
├─ 错题本
└─ 避坑指南

系统
├─ 模板管理
├─ 模型设置
├─ 插件连接
└─ 数据设置
```

### 4.2 左侧功能要求

- 分类支持新增、重命名、删除、拖拽排序；
- 标签支持合并、重命名、批量移除；
- 智能视图由系统自动生成；
- 用户可以固定常用视图；
- 待整理内容必须明显提醒；
- 分类和标签不能强制用户一开始就配置。

## 7. 笔记列表页

当用户点击某个分类、标签或智能视图时，中间显示笔记列表。

列表字段：

```text
标题
摘要
标签
分类
来源
更新时间
状态
是否收藏
```

列表支持：

- 卡片视图；
- 列表视图；
- 按时间排序；
- 按相关度排序；
- 按类型过滤；
- 批量操作。

## 9. 待整理区设计

待整理区不是主页面，但很重要。

来源：

- 手动导入；
- 浏览器插件；
- CLI；
- IDE；
- 文件导入。

待整理列表：

```text
来源 | 标题 | 采集时间 | 内容长度 | 推荐类型 | 操作
```

操作：

```text
整理成笔记
丢弃
合并到已有笔记
查看原始内容
稍后处理
```

整理后进入草稿状态，用户确认后才进入正式知识库。

---

## 10. 主页面开发优先级

### 第一优先级

- 三栏布局；
- 左侧导航；
- 中间笔记列表；
- 中间笔记详情；
- 右侧 AI 对话栏占位；
- 顶部搜索栏；
- 设置入口。

### 第二优先级

- Markdown 编辑器；
- 标签分类；
- 搜索；
- 笔记状态；
- 模型配置；
- 当前笔记 AI 问答。

### 第三优先级

- 全库 RAG；
- AI 写回笔记；
- 版本历史；
- 学习卡片；
- 每日回顾。
